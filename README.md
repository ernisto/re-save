## Installation

- Download (`resave.rbxm`) from [latest release](https://github.com/ernisto/re-save/releases/latest)

- Wally (`wally.toml`): add under `[dependencies]`
```toml
resave = "ernisto/re-save@0.1.0-alpha.7"
```

- Pesde in roblox (terminal):
```sh
pesde add wally#ernisto/re-save
```
